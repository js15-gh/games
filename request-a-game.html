What makes a request easy to build

The thing that stalls a game is almost never the code — it's the rules. Card games in particular vary from family to family, and an approximation is worse than nothing, because a game with the wrong rules just causes the arguments it was meant to end.

  • Exact values. If cards or tiles carry points, list every one and what the total should come to. That total is how we check we've understood.
  • Who wins a round, and what happens on a tie.
  • How the game ends — a target score, a fixed number of rounds, or last player standing.
  • Anything secret. If some information is hidden from some players, say who sees what and when it's revealed. That's usually the part a phone helps most with.

Mahjong for four players, and better tools for people who play with the same group regularly — planning a party's games in advance, and carrying a scoreboard from one night to the next. If either would be useful to you, say so in the form; it moves things up the list.
