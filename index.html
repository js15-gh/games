DESI PARTY GAMES!

Games for a group in one room, each playing on their own phone. Create a game, share the link, and everyone joins the same table.

How it works

  1. One person opens a game and taps Create. They get a four-character code.
  2. They share the link — everyone else opens it, or types the code in.
  3. Everyone plays on their own phone, in the same room, on the same live game.
