How to play Sudoku

  1. Fill every empty square with a digit so that each row, each column and each outlined box contains every digit exactly once.
  2. Start with the 4×4 if you have never done one — it is the same puzzle with less of it, and a six-year-old can finish one.
  3. Every puzzle here has exactly one answer, so you never have to guess. If you are stuck, there is always a square somewhere that only one digit can go in.

An example

In a 4×4, look at a row that already has 1, 3 and 4. The empty square must be 2 — nothing else is left. That is the whole game: find the square with only one possibility, fill it in, and it gives you the next one. Use Notes to pencil in the digits a square could still take when there is more than one.
